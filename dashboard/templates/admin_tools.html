HOW TO THINK ABOUT IT

Three Simple Rules

1. Want to try an API? Start in API Lab.

2. Want City Manager OS to keep checking it? Add it in Integrations Center and test it before activating.

3. Want a notification? Let the source normalize into the existing Watchlist and Subscriber routing system. Do not hard-code recipients.
