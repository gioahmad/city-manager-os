How onboarding works

Integration Monitor API Lab

Create a source even when credentials or the final endpoint are not available. Sources remain NEEDS SETUP or PAUSED until configuration is complete.

Activation requires a successful read-only TEST of the current connection/parser configuration. Changing endpoint, auth, request, adapter, parser or transport settings invalidates the prior TEST and automatically pauses an active source.

Secrets are referenced only by environment-variable name. Values are never stored or displayed here. Notifications continue through the existing Attention / Watchlist / Routing / Delivery Guard architecture.
